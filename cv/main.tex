\hfill
\href{https://github.com/saifibnaezhararko/QVTM}{[GitHub]}

\begin{itemize}
    \item Implemented a Quantum Variable Topic Model leveraging variational quantum circuits for unsupervised topic discovery, developed for the \textbf{Global Quantum Hackathon 2024}.

    \item Designed an encoder--decoder architecture employing \textbf{amplitude embedding} to represent classical text data within the quantum Hilbert space.

    \item Optimized the model using a composite objective combining \textbf{KL-divergence}, \textbf{Cross-Entropy}, and \textbf{Maximum Mean Discrepancy (MMD)} loss functions.

    \item Achieved superior performance with a \textbf{Topic Diversity score of 1.0} and improved coherence over traditional Latent Dirichlet Allocation (LDA) baselines.

    \item Developed entirely in Python (Jupyter Notebook) using a quantum machine learning stack.
\end{itemize}
